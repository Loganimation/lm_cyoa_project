#  ![Pregnancy Simulator](image.png)
### An choice based adventure game
#### BY LOGANIMATION / LOGAN MYERS
____
*Estimated time to complete full game with all endings: ~8 minutes*

This game realistically simulates what its like to be a pregnant woman and the temptations you must face in order to give birth safely. There are 5 possible endings you can collect, have fun or something!

### Normal Endings
+  The Intentional Way to Play the Game Ending or Something Like That
+  Irresponsible
+  Rituals
+  Apitimy of Stupidity
### Secret Endings
+  Your Special Ending
+  Fate

**NOT RECOMMENDED FOR YOUNGER AUDIENCES (12+)**

**BEST PLAYED WITH TERMINAL FULL WINDOWED**
